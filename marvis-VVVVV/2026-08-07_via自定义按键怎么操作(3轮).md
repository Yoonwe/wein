老板，VIA（键盘配置工具，配合 QMK 固件键盘使用）自定义按键的操作步骤如下：

## 一、准备阶段

1. **连接键盘**：用数据线连接键盘（VIA 不支持无线模式改键，需有线连接）
2. **打开 VIA**：访问 [usevia.app](https://usevia.app)（网页版）或下载桌面版
3. **授权固件**：如果键盘提示"未授权"，需在键盘的 `keymap.c` 中加入 `#define VIA_ENABLE` 并刷入固件，或按键盘官方说明开启授权

## 二、自定义按键核心操作

### 1. 进入改键界面
- 打开 VIA 后，点击左侧 **CONFIGURE（配置）** 标签页

### 2. 选择图层
- 顶部有 **LAYER 0 / 1 / 2 / 3** 图层切换，默认改 Layer 0（主层）
- 想设置 FN 组合键，就把特殊按键放到 Layer 1/2 等上层

### 3. 改键
- 点击键盘图上要改的按键（高亮选中）
- 从右侧按键库中选择目标功能（如字母、功能键、宏、多媒体键等）
- 点击后按键即刻生效（VIA 是实时写入键盘的，无需刷固件）

### 4. 常用特殊按键
| 按键类型 | 说明 |
|---|---|
| **MO(n)** | 按住临时切换到第 n 层（FN 键常用） |
| **LT(n, key)** | 轻按触发按键，长按切换图层 |
| **TG(n)** | 单击切换图层开关 |
| **MT(mod, key)** | 轻按为按键，长按为修饰键（如 `MT(LCTL, ESC)`） |
| **宏 (Macros)** | 录制/编辑一串按键序列 |

### 5. 调整旋钮/灯光等
- 旋钮编码器、RGB 灯光等在 **CONFIGURE** 页的对应区域或 **LIGHTING** 标签页调整

## 三、保存与注意事项

1. **自动保存**：VIA 改键即时写入键盘，无需手动保存，拔线后依然生效
2. **恢复默认**：可在 **SETTINGS** 中点击 "Restore default keymap"（需固件内置默认键位）
3. **注意**：若改键后键盘失灵，重新插拔或刷回原固件即可恢复

老板，小顺 Flow 2 支持 VIA 改键，但有几个该型号特有的步骤，和标准 VIA 流程不同。

---

## 小顺 Flow 2 VIA 改键完整流程

### 一、前置准备

1. **必须用有线模式连接**，VIA 不能在蓝牙/2.4G 下改键
2. 从洛斐官网或产品页面下载 Flow 2 的 **VIA JSON 文件**（有线版和 2.4G 版各一个，Flow 2 不在 VIA 官方数据库里，必须手动导入）
3. 打开 [usevia.app](https://usevia.app) 或桌面版 VIA

### 二、加载 JSON（关键步骤，缺了认不出键盘）

1. 点击右上角 **Settings（设置）图标**
2. 打开 **Show Design tab** 开关
3. 顶部出现 **Design 标签页** → 点击
4. 点击 **Load**，选择下载的 JSON 文件
5. 切换到 **Configure（配置）** 标签页，此时应能看到 Flow 2 的键位布局图

> 提示：如果加载后报红字错误，点击 "Use V2 definitions (deprecated)" 再重新导入一次。

### 三、改键操作

**图层机制**：顶部 LAYER 0-3，Layer 0 是主层，Layer 1/2/3 用于 FN 组合层。

- 点击键盘图上目标按键 → 从右侧按键库选择新功能 → 即时生效
- 常用图层键：`MO(1)` 按住切层、`LT(1, key)` 轻按触发/长按切层、`TG(1)` 开关层

### 四、Flow 2 专属要点

**连接模式切换按键（特殊键码）**

蓝牙 1/2/3、2.4G 切换、恢复出厂设置这些功能键不在常规按键库中，需要用 **ANY 键** 手动输入键码：

| 功能 | 键码 |
|---|---|
| 蓝牙设备 1 | `0x5D,0x25,0xBF` |
| 蓝牙设备 2 | `0x5D,0x25,0xBE` |
| 蓝牙设备 3 | `0x5D,0x25,0xBD` |
| 2.4G 配对 | `0x5D,0x25,0xB2` |
| 恢复出厂设置 | `0x5D,0x25,0xB1` |

操作方法：在右侧按键库搜索 **ANY** → 拖到目标位置 → 在弹出的框里输入上述键码。

> **重要提醒**：改键前建议先导出备份当前布局（SAVE + EXPORT），否则误清连接模式键后很难恢复。

**Touch Bar 自定义**

右侧 Touch Bar 也支持 VIA 改键，在 CONFIGURE 页面会显示为独立按键位，可以绑定为：音量 +/-、亮度 +/-、缩放、媒体控制、宏等。默认是音量/亮度调节。

**不同连接模式需要不同 JSON**

- 有线模式导入有线 JSON
- 2.4G 模式导入 2.4G JSON
- 改键只在对应连接模式下生效，如果两个模式都要改键，需要分别加载 JSON 后分别配置

**宏录制**

VIA 左侧 **MACROS** 标签页 → 新建宏 → 录制按键序列 → 回到 CONFIGURE 将 `M0`/`M1` 等拖到目标按键。

### [Marvis · 2026-08-07 13:56:19]

老板，这里有个关键概念要分清：**VIA 里点图层 ≠ 键盘切图层**。

---

## 一、为什么"切不过去"

VIA 顶部 **LAYER 0/1/2/3** 点击切换的只是**编辑视图**——你点 Layer 1 是在"编辑第 1 层的内容"，它不会让键盘实际切到第 1 层。

键盘要**实际切换图层**，必须按到某个映射了图层切换键码（`MO` / `TG` / `LT` / `DF`）的实体按键。

你现在"一直停留在第 0 层"的最可能原因：

| 原因 | 说明 |
|---|---|
| 第 0 层没有设置图层切换键 | 最典型：第 0 层里没有 FN 键，或 FN 键被改掉了 |
| 切层键被误改 | 原来的 FN 键被你改成别的功能了 |
| 用错键码 | 改的是 `MO(1)`（按住才切）却只点了一下，松手就回 0 层 |

## 二、正确的切层方式

在第 0 层（LAYER 0 视图下）找一个顺手的键，改成以下任一功能：

| 键码 | 行为 | 适合 |
|---|---|---|
| `MO(1)` | 按住进第 1 层，松手回 0 层 | FN 组合键 |
| `TG(1)` | 单击切到第 1 层并**锁定**，再单击切回 | 你想一直待在第 1 层 |
| `LT(1, 空格)` | 轻按是空格，长按切到第 1 层 | 省一个键位 |
| `DF(1)` | 把第 1 层设为默认层，开机就在第 1 层 | 永久切换 |

你想"切过去一直停留"就选 **`TG(1)`**——单击切过去，再单击切回来。

## 三、第 0 层重置

可以重置，三种方式：

**方式 1：恢复出厂（最彻底）**
键盘上按之前给你的键码 `0x5D,0x25,0xB1`（ANY 键输入）恢复出厂设置，所有图层回到默认。

**方式 2：导入默认布局**
- 下载 Flow 2 的默认布局文件（`flow2_lofree.layout_default.json` 之类）
- Design 标签页 → Load 导入，会覆盖当前全部图层配置

**方式 3：仅重置第 0 层（推荐，不影响你改的第 1 层）**
- 切到 LAYER 0 视图
- 逐个把改错的键点回原功能
- 如果你有之前导出的备份布局，直接 SAVE → LOAD 恢复备份

## 四、你现在最该做的

1. 切到 **LAYER 0** 视图，检查第 0 层有没有 `MO(1)` / `TG(1)` 之类的键——**八成是没了**
2. 找一个闲置键（如右下角 Ctrl 旁边的键），改成 `TG(1)`
3. 单击它，键盘就切到第 1 层，此时按第 1 层里改过的键验证是否生效
4. 恢复默认建议用**方式 1**（出厂键码），一步到位，比手动逐键改快

改完记得 SAVE → EXPORT 备份一份，避免下次又弄丢。
