### [AI · 2026-08-07 15:19:20]

老板，VIA 本质是给 QMK 键盘做键位和宏配置的，编程场景下宏按键的设计思路就是"把高频组合操作变成单键触发"。给你按优先级分几类：

## 一、成对符号自动补全（最推荐）

程序员打代码最烦的就是输入成对符号后光标停在中间，宏可以直接输出"符号对 + 左移一格"：

| 宏 | 输出内容 | 效果 |
|---|---|---|
| 圆括号对 | `()` + 左移 | 输入 `(` 自动出 `()` 光标进括号内 |
| 花括号对 | `{}` + 左移 | 同上，配合换行可输出 `{\n}` 光标居中 |
| 方括号对 | `[]` + 左移 | 同上 |
| 双引号/单引号 | `""` + 左移 | 字符串直接开写 |
| 反引号对 | ` `` ` + 左移 | Markdown 行内代码 |

这类建议用 **Tap Dance**（点按一次出符号，双击出成对+换行）或放在符号层，不占用主键区。

## 二、高频代码片段（放拇指键或符号层）

| 宏 | 输出 | 适用语言 |
|---|---|---|
| 日志输出 | `console.log();` + 左移 | JS/TS |
| 打印 | `print()` / `System.out.println()` + 左移 | Python/Java |
| 箭头函数 | `=> ` | JS |
| 注释块 | `/* */` 光标居中 或 `// ` | 通用 |
| 导入语句 | `import xxx from 'xxx'` 模板 | JS/TS |

注意：这类宏建议**只放高频且无歧义的**，否则宏太多反而记不住。

## 三、高频组合快捷键（编程刚需）

VIA 宏支持按键序列，把 IDE 里高频快捷键固化成单键：

| 宏 | 按键序列 | 用途 |
|---|---|---|
| 格式化代码 | `Ctrl+Shift+F` / `Ctrl+Alt+L` | 对齐格式 |
| 复制当前行 | `Ctrl+D` | VSCode 复制行 |
| 多行注释切换 | `Ctrl+/` | 注释切换 |
| 查找引用 | `Shift+F12` / `Ctrl+Shift+F10` | 跳转引用 |
| Git 提交面板 | `Ctrl+Shift+G` | 版本控制 |

## 四、特殊字符组合（符号层主力）

编程里高频的组合符号，直接绑在符号层（按住某个键进入）：

`=>` `->` `::` `!=` `===` `!==` `+=` `&&` `||` `#include` 前缀等。

## 放置位置建议

- **拇指键**：空格旁边的键适合放"成对符号 + 回车换行"这种组合宏
- **符号层**：设一个 `MO(1)` 层，把 F 键区或数字行映射成特殊符号
- **Tap Dance**：一个键点按/双击/长按三种行为，比如 `Esc` 双击变 `Ctrl+``（终端开关）

**最实用的起步组合**：圆括号对 + 花括号对 + 双引号对 + 格式化代码 + `console.log()`，这五个基本能覆盖日常 80% 的重复输入。
