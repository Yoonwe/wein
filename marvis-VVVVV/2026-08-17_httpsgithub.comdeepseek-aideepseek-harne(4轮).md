| 形态 | 命令 | 说明 |

```

cd dsh-TUI
dsh plugin --profile tui add file:$(pwd)
dsh --profile tui
```

1. 该插件是第三方社区项目（非 DeepSeek 官方），需要联网克隆 GitHub 仓库
