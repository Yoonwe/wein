免费层之外全是付费点：更高配置、固定公网 IP 数量、块存储扩容、快照、负载均衡、监控告警……**免费的是"入门体验卡"，收费的是"生产力工具"**。

## 核心区别：花谁的钱

| | 借记卡（储蓄卡） | 信用卡 |
|---|---|---|
| **资金性质** | 花**你自己**存进去的钱 | 花**银行借给你**的钱 |
| **能否透支** | 不能，卡里没钱就刷不了 | 能，银行给授信额度，先消费后还款 |
| **账户逻辑** | 对应你的存款账户 | 对应一笔循环授信（本质是短期贷款） |
| **还款** | 不需要还款，钱本来就是你自己的 | 每月有账单日和还款日，需按时还款 |
| **利息** | 存款还有利息 | 全额还款有**免息期**（一般 20~56 天），逾期或分期才收利息 |
| **征信** | 开卡一般不上征信 | 申请、额度、还款记录**全部上征信**，逾期影响个人信用 |

## 举个具体例子

- **借记卡**：卡里有 5000 块，想买个 8000 块的手机 → **刷不了**；
- **信用卡**：额度 2 万，卡里一分钱没有，照样能买 8000 块的手机 → 到还款日前把钱还上，一分利息不花；还不上就按日息计费。

所以信用卡的本质是：**银行给你的一个可循环使用的小额贷款额度 + 一段免息期**。银行赚的是你逾期/分期的利息、商户手续费、年费；你赚的是免息资金占用和积分权益。

## 为什么说"本质上不同"

- 借记卡是你和银行之间的**存款关系**（你存钱，银行保管）；
- 信用卡是你和银行之间的**借贷关系**（银行借钱给你，你承诺还）。

一个是"我的钱"，一个是"借的钱"，从法律性质到资金流向都完全不是一回事。
