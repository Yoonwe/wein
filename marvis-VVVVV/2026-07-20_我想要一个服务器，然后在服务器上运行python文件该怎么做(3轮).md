### 快速上手三步

**1. 生成密钥（一次性）**
```powershell
ssh-keygen -t ed25519 -C "你的邮箱"
```

**2. 上传公钥到服务器**
```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@服务器IP "cat >> ~/.ssh/authorized_keys"
```

**3. 连接**
```powershell
ssh root@服务器IP
```

---

### 没有云服务器？用 WSL2 练手

在 WSL2 里 `sudo apt install openssh-server -y && sudo service ssh start`，然后用 `ip addr` 拿到 WSL2 的 IP，本机直接 `ssh 用户名@WSL的IP` 即可。

### 最值得记住的两个技巧

- **Config 快捷别名**：编辑 `~/.ssh/config`，之后 `ssh myserver` 代替一长串 IP 和端口
- **端口转发**：`ssh -L 3306:localhost:3306 root@服务器IP`，把远程数据库映射到本地

# Linux 云服务器初始化完整清单（Ubuntu 22.04）

> 适用场景：刚拿到一台全新云服务器（仅有 root 密码 + 公网 IP），目标：SSH 免密登录 + 运行 Python 脚本。

---

## 1. 首次 SSH 登录 & 修改 root 密码

```bash
# 本地终端执行（替换为你的服务器 IP）
ssh root@你的服务器IP

# 登录成功后立刻改密码
passwd
```

---

## 2. 创建普通用户并授予 sudo 权限

```bash
# 创建用户（替换 youruser 为你的用户名）
adduser youruser

# 加入 sudo 组
usermod -aG sudo youruser

# 验证 sudo 权限（切换到新用户后执行）
su - youruser
sudo whoami   # 应输出 root
```

---

## 3. 配置 SSH 密钥登录 + 安全加固

### 3.1 本地生成密钥对（如果没有）

```bash
# 本地终端执行
ssh-keygen -t ed25519 -C "your_email@example.com"
```

### 3.2 上传公钥到服务器

```bash
# 本地终端执行（macOS/Linux 自带 ssh-copy-id）
ssh-copy-id -i ~/.ssh/id_ed25519.pub youruser@你的服务器IP

# Windows 手动方式：
# 先在本地 cat ~/.ssh/id_ed25519.pub 复制内容
# 然后 SSH 到服务器执行：
mkdir -p ~/.ssh && chmod 700 ~/.ssh
echo "粘贴你的公钥内容" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### 3.3 验证免密登录

```bash
ssh youruser@你的服务器IP   # 应直接登录，不提示密码
```

### 3.4 安全加固：禁用密码登录 & 禁止 root SSH

```bash
sudo sed -i 's/^#PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/^#PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -i 's/^PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config

# 确认修改生效
sudo grep -E "PermitRootLogin|PasswordAuthentication" /etc/ssh/sshd_config

# 重启 SSH 服务
sudo systemctl restart sshd

# ⚠️ 先保持当前窗口不关，另开终端测试免密登录是否正常，确认无误再关旧窗口
```

---

## 4. 更新系统 & 安装 Python 工具链

```bash
# 更新包列表并升级
sudo apt update && sudo apt upgrade -y

# Ubuntu 22.04 自带 Python 3.10，确认版本
python3 --version

# 安装 pip
sudo apt install python3-pip -y

# 安装 venv（虚拟环境）
sudo apt install python3-venv -y

# 安装常用开发工具
sudo apt install build-essential python3-dev -y

# （可选）安装 uv —— 更快的 Python 包管理器
curl -LsSf https://astral.sh/uv/install.sh | sh
```

---

## 5. 防火墙配置

```bash
# 启用 ufw
sudo ufw enable

# 开放 SSH 端口（必须先做，否则可能断连）
sudo ufw allow 22/tcp

# 如果你的 Python 应用需要对外暴露端口（例如 Flask 5000）
sudo ufw allow 5000/tcp

# 查看规则
sudo ufw status verbose
```

> 云服务商的安全组（阿里云/腾讯云/AWS）也需要在控制台放行对应端口。

---

## 6. 上传本地 Python 文件到服务器

```bash
# 方式一：scp（单文件 / 目录）
scp /本地/路径/script.py youruser@你的服务器IP:/home/youruser/
scp -r /本地/项目目录 youruser@你的服务器IP:/home/youruser/

# 方式二：rsync（增量同步，推荐大项目使用）
rsync -avz /本地/项目目录/ youruser@你的服务器IP:/home/youruser/项目目录/
```

---

## 7. Python 脚本后台持续运行

### 方式一：nohup（最简单，适合临时跑）

```bash
nohup python3 /home/youruser/script.py > output.log 2>&1 &

# 查看进程
ps aux | grep script.py
# 停止
kill <PID>
```

### 方式二：tmux（断线后可重连查看）

```bash
sudo apt install tmux -y
tmux new -s myapp
python3 /home/youruser/script.py

# Ctrl+B 然后按 D 分离（脚本继续运行）
# 重新连接
tmux attach -t myapp
```

### 方式三：systemd（推荐生产环境）

```bash
sudo tee /etc/systemd/system/myapp.service << 'EOF'
[Unit]
Description=My Python App
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/home/youruser
ExecStart=/usr/bin/python3 /home/youruser/script.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl start myapp
sudo systemctl enable myapp

# 查看状态 / 日志
sudo systemctl status myapp
sudo journalctl -u myapp -f
```

## 本地 SSH Config 简化（可选）

编辑 `~/.ssh/config`，添加：

```
Host myserver
    HostName 你的服务器IP
    User youruser
    IdentityFile ~/.ssh/id_ed25519
```

之后只需 `ssh myserver` 即可登录，scp 也简化为 `scp file myserver:~/`。

kill <PID>
```

### 方式二：tmux（断线后可重连查看）

```bash
sudo apt install tmux -y
tmux new -s myapp
python3 /home/youruser/script.py

# Ctrl+B 然后按 D 分离（脚本继续运行）
# 重新连接
tmux attach -t myapp
```

### 方式三：systemd（推荐生产环境）

```bash
sudo tee /etc/systemd/system/myapp.service << 'EOF'
[Unit]
Description=My Python App
After=network.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/home/youruser
ExecStart=/usr/bin/python3 /home/youruser/script.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl start myapp
sudo systemctl enable myapp

# 查看状态 / 日志
sudo systemctl status myapp
sudo journalctl -u myapp -f
```

Host myserver
