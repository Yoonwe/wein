### [Marvis · 2026-07-25 14:45:04]

是的，基本逻辑是对的。公积金个人缴存部分可以在计算个人所得税时**税前扣除**，比例越高，扣除额越大，应纳税所得额就越低。

---

## 深圳公积金的个税扣除规则

| 项目 | 规则 |
|------|------|
| 缴存比例范围 | 单位和个人各 **5% ~ 12%**，由单位选定 |
| 个人缴存部分 | 全额在个税前扣除，不并入综合所得 |
| 单位缴存部分 | 同样免税，不计入个人应税收入 |
| 缴存基数上限 | 深圳市上年度社平工资 × 3（2025年上限约 43,695 元/月） |
| 扣除上限 | 基数上限 × 个人比例，超上限部分**不能税前扣除** |

---

## 举例对比

假设月薪 30,000 元（未超基数上限），不考虑其他扣除：

| 公积金比例 | 个人月缴存 | 年税前扣除 | 年应纳税所得减少 |
|-----------|-----------|-----------|----------------|
| 5% | 1,500 | 18,000 | 18,000 |
| 12% | 3,600 | 43,200 | 43,200 |

按 20% 边际税率估算，12% 比例每年可少缴个税约 **5,000 元**，比 5% 比例多省约 **3,000 元**。

---

## 需要注意

1. **比例不由你个人决定**——由单位统一设定，且一个单位内所有职工比例一致。
2. **钱不是"消失"的**——公积金进入个人账户，可用来还房贷、租房提取、退休销户全额提取，本质是强制储蓄 + 免税。
3. **别只看避税**——比例高到手现金会减少，需结合自身现金流需求权衡。

所以结论是：在深圳，公积金比例从 5% 提到 12%，合法的节税效果是实实在在的，前提是你所在单位愿意调高比例。

### [Marvis · 2026-07-25 14:46:24]

深圳个税采用**累计预扣法**，计算公式如下：

---

## 核心公式

```
应纳税额 = 累计应纳税所得额 × 税率 - 速算扣除数 - 已预缴税额
```

其中：

```
累计应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用 - 累计专项扣除 - 累计专项附加扣除 - 累计其他扣除
```

---

## 各扣除项详解

| 扣除类别 | 项目 | 标准 |
|----------|------|------|
| **减除费用** | 基本减除 | 5,000 元/月（60,000 元/年） |
| **专项扣除** | 社保个人部分 | 养老 8% + 医疗 2% + 失业 0.3%（按实际基数） |
| | **公积金个人部分** | 缴存基数 × 比例（5%~12%） |
| **专项附加扣除** | 子女教育 | 2,000 元/月/孩 |
| | 继续教育 | 400 元/月（学历）或 3,600 元/年（职业资格） |
| | 住房贷款利息 | 1,000 元/月（首套房） |
| | 住房租金 | 1,500 元/月（深圳标准） |
| | 赡养老人 | 3,000 元/月（独生子女） |
| | 婴幼儿照护 | 2,000 元/月/孩 |
| **其他扣除** | 年金/商业健康险等 | 按实际 |

---

## 税率表（综合所得，按年累计）

| 级数 | 累计应纳税所得额 | 税率 | 速算扣除数 |
|------|----------------|------|-----------|
| 1 | ≤ 36,000 | 3% | 0 |
| 2 | 36,001 ~ 144,000 | 10% | 2,520 |
| 3 | 144,001 ~ 300,000 | 20% | 16,920 |
| 4 | 300,001 ~ 420,000 | 25% | 31,920 |
| 5 | 420,001 ~ 660,000 | 30% | 52,920 |
| 6 | 660,001 ~ 960,000 | 35% | 85,920 |
| 7 | > 960,000 | 45% | 181,920 |

---

## 完整计算示例

假设：月薪 30,000 元，公积金 12%（基数 30,000），无专项附加扣除。

**1. 计算每月扣除项：**

| 项目 | 金额 |
|------|------|
| 减除费用 | 5,000 |
| 社保（养老8%+医疗2%+失业0.3%） | 3,090 |
| 公积金 12% | 3,600 |
| **月扣除合计** | **11,690** |

**2. 逐月累计计算（前3个月）：**

| 月份 | 累计收入 | 累计扣除 | 累计应纳税所得额 | 税率 | 速算扣除 | 累计应纳税额 | 当月应缴 |
|------|---------|---------|----------------|------|---------|------------|---------|
| 1月 | 30,000 | 11,690 | 18,310 | 3% | 0 | 549.30 | 549.30 |
| 2月 | 60,000 | 23,380 | 36,620 | 10% | 2,520 | 1,142.00 | 592.70 |
| 3月 | 90,000 | 35,070 | 54,930 | 10% | 2,520 | 2,973.00 | 1,831.00 |

> 2月累计应纳税所得额 36,620 进入第2级，税率跳至10%。

**3. 全年个税总计：**

累计应纳税所得额 = 360,000 - (11,690 × 12) = 360,000 - 140,280 = **219,720**

对应税率 20%，速算扣除 16,920：

全年应纳税 = 219,720 × 20% - 16,920 = **27,024 元**

## 计算顺序

```
税前工资
  ↓ 先扣：社保个人部分（养老8% + 医疗2% + 失业0.3%）
  ↓ 再扣：公积金个人部分（5%~12%）
  ↓ 再扣：5,000 元基本减除
  ↓ 再扣：专项附加扣除（如有）
  ───────────────────────────
  = 应纳税所得额 → 这才拿去套税率算税
```

---

## 举例

税前月薪 15,000，公积金 5%：

| 步骤 | 金额 |
|------|------|
| 税前工资 | 15,000 |
| 扣社保（10.3%） | -1,545 |
| 扣公积金（5%） | -750 |
| **到手前余额** | 12,705 |
| 扣基本减除 | -5,000 |
| 应纳税所得额 | **7,705** |
| 套 10% 税率 | 770.5 - 252 = **约 518 元个税** |

---

所以五险一金既是"先扣掉"的项目，也是免税的——扣得越多，后面算税的分母越小。这也解释了公积金比例提到 12% 能节税的原因：多扣的公积金不进税基，相当于合法降低了应税收入。
