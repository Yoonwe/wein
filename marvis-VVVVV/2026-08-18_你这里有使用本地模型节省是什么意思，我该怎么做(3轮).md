### [Marvis · 2026-08-18 14:52:18]

"使用本地模型节省"是指：让 AI 工具把简单、重复的任务交给**在你自己电脑上运行的模型**处理，而不是每次都调用云端付费 API。本地模型不花钱、不限流、响应快，但能力比云端大模型弱。

**这样做能省什么**
- 省钱：本地推理零费用（如 Ollama + Llama/Qwen 系列）
- 省流量：数据不出本机，也更快
- 省配额：减少云端 API 调用次数，避免限流

**适合交给本地模型的任务**
格式转换（JSON/YAML/Markdown 互转）、简单查询、信息提取、文本归类等低复杂度操作。

**不适合的任务**
代码审查、创意写作、复杂推理、长文档总结——本地小模型质量不够，省了钱但出错返工反而更费。

**具体怎么做（通用路径）**
1. 安装本地推理引擎：`Ollama`（最省事）或 `LM Studio`
2. 拉取一个中小模型，例如 `ollama pull llama3.2` 或 `qwen2.5:7b`
3. 在 AI 工具/客户端的模型设置里找到"使用本地模型 / 本地推理 / 节省模式"选项，填入本地模型地址（默认 `http://localhost:11434`）
4. 开启后，工具会自动把简单任务路由到本地模型

### [Marvis · 2026-08-18 14:57:39]

取决于工具的配置方式，分两种情况：

**自动切换（推荐）**
- 工具按**任务类型**自动路由：简单任务（格式转换、提取、简单查询）自动走本地模型，复杂任务（代码审查、深度分析）自动走云端大模型
- 典型配置就是给工具指定 `localModelTasks` 列表，命中列表的任务自动用本地模型，其余走云端，全程无需手动干预
- 进阶玩法是 fallback：默认用本地/便宜模型，遇到失败或质量不足时自动降级到云端强模型

**手动切换**
- 有些工具只是提供一个模型下拉框，需要你根据当前任务手动选择本地或云端，不会自动判断

**我的建议**
选带自动路由的方案，理由：手动切容易忘，复杂任务误走本地模型会质量塌方，简单任务误走云端又浪费钱。自动按任务类型分流才是"节省"的正确打开方式——省了成本又不牺牲质量。

### [Marvis · 2026-08-18 14:58:32]

Marvis 里的"本地模型"就是**隐私模式（本地模式）**，切换是**手动**的——不会按任务自动分流，需要你自己切。方法如下：

**操作步骤**
1. 点击左下角**头像**，展开菜单
2. 选择 **AI 模式 / 运行模式**
3. 切换为**隐私模式（本地模式）**，切换无需重启，立即生效

**切过去之后**
- 推理全部走本地 Qwen 端侧模型，数据零上传，断网可用
- 首次启用需联网下载约 **2GB** 本地模型文件，下载完成后可完全离线
- 代价是响应更慢、能力弱于云端（效率模式用的混元 + DeepSeek-V4）

**你这台机器的可行性**
我查了你的配置：i5-14400（10 核 16 线程）+ 32GB 内存。本地模式的硬件门槛约是 16 核 CPU + 32GB 内存起步，你的配置正好卡在临界线——内存达标，CPU 物理核数略低。设置里如果"本地模式"按钮是灰的，就是被硬件门槛拦住了；能点开就能用，只是大任务会偏慢。

**建议**
日常任务留在效率模式，处理合同、财务、隐私文件这类敏感内容时再手动切到隐私模式。
