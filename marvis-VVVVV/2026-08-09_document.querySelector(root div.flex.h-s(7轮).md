## 获取整个表格数据的三种方案

### 方案 A：DOM 抓取（简单粗暴，适合一次性）

```javascript
// 拿到表格所有行数据
const rows = [...document.querySelectorAll(
  '#root .compass-table .ant-table-body tbody tr'
)].map(tr =>
  [...tr.querySelectorAll('td')].map(td => td.innerText.trim())
);
console.table(rows);
```

优点：无依赖直接跑；缺点：拿到的是**渲染后的文本**，丢失原始数据类型（如数字、ID、嵌套对象），且分页时只拿到当前页。

### 方案 B：React 内部状态（最推荐，拿到结构化原始数据）

表格数据必然存在组件的 state/props 里，antd 表格数据源通常是 `dataSource` 数组：

```javascript
// 通过 React fiber 拿到组件实例，再找 dataSource
const el = document.querySelector('#root .compass-table .ant-table-wrapper');
// 或者直接从根节点向下遍历 fiber 树
const fiberKey = Object.keys(el).find(k => k.startsWith('__reactFiber$'));
let fiber = el[fiberKey];
let dataSource = null;

while (fiber && !dataSource) {
  const memoizedProps = fiber.memoizedProps || {};
  if (memoizedProps.dataSource) {
    dataSource = memoizedProps.dataSource;
    break;
  }
  fiber = fiber.return;
}
console.log(dataSource);
```

优点：拿到**完整原始 JSON**，包含所有字段、类型、隐藏列；缺点：依赖 React 内部结构，版本升级可能变化。

### 方案 C：抓接口（最稳定，适合长期使用）

打开 DevTools → Network 面板，刷新页面，过滤 XHR/Fetch，找到返回表格数据的请求（通常在 `Response` 里能看到 `dataSource` 结构），直接调接口拿 JSON：

```javascript
// 示例：假设接口是 GET /api/compass/list
const res = await fetch('/api/compass/list', { credentials: 'include' });
const data = await res.json();
```

优点：数据最全、可拿全部分页、最稳定；缺点：需要找到接口地址，可能需要处理签名参数。

| 场景 | 推荐方案 |
|---|---|
| 一次性快速看数据 | A（DOM） |
| 需要结构化数据做分析/脚本 | B（React state） |
| 长期自动化、要全量数据 | C（接口） |
