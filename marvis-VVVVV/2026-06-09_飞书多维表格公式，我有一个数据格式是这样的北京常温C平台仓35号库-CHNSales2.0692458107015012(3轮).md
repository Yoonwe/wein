---

### 方案一：数据预处理（最推荐）

在数据进入多维表格前，用脚本把 JSON 扁平化。例如用 Python 预处理：

```python
import json

data = {...}  # 你的JSON
target_sku = "6924581070150"

total = sum(
    wh.get("Sales", {}).get("2.0", {}).get(target_sku, 0)
    for wh in data.values()
)
```

预处理后直接得到汇总值存入多维表格。**一步到位，无公式复杂度。**

---

### 方案二：飞书多维表格「脚本」字段

如果已开通飞书高级功能，用 JavaScript 脚本字段：

```javascript
const data = JSON.parse($$('数据表2.数据1'));
const sku = $$('字段1');

let total = 0;
for (const wh of Object.values(data)) {
  total += wh?.Sales?.['2.0']?.[sku] || 0;
}
return total;
```

## 重要限制

1. **全局匹配，不区分 Sales / gift / Maintain**：`REGEX_EXTRACT` 无法判断 SKU 所在的父级路径。如果某 SKU 在 gift 中也出现，会被一并计算

在飞书多维表格的 `REGEX_EXTRACT` 中使用以下写法：

| 需求 | 正则写法 | 说明 |
|---|---|---|
| 匹配任意字符（不含换行） | `.*` | 贪婪，匹配到末尾 |
| 匹配任意字符（不含换行） | `.*?` | 非贪婪，匹配到下一个条件即停 |
| 匹配任意字符（**含换行**） | `[\s\S]*` | `\s`=空白(含换行) + `\S`=非空白 = 所有字符 |
| 同上（含换行） | `[\w\W]*` | `\w`=字母数字下划线 + `\W`=反义 |
| 同上（含换行） | `[\d\D]*` | `\d`=数字 + `\D`=非数字 |
