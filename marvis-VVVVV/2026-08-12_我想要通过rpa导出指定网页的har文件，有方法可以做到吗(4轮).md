| 方案 | 实现方式 | 优点 | 缺点 | 推荐度 |
|------|---------|------|------|--------|
| Playwright 录制 | `record_har_path` 参数，浏览器操作完自动落盘 HAR | 一行参数搞定，可自定义录制范围，不依赖外部工具 | 需要 playwright 环境（影刀 Python 指令里可跑） | ★★★★★ |
| Selenium-wire | `driver.har` 直接取 HAR dict | API 简单，逻辑清晰 | chromedriver 版本需严格匹配，偶尔有兼容坑 | ★★★★ |
| Fiddler / Charles | 浏览器走代理，操作完手动 Export Sessions → HAR | 零代码，最不折腾，还能看实时流量 | 需要手动导出，不适合全自动流程 | ★★★★ |
| Chrome netlog 转 HAR | 启动参数加 `--log-net-log=xx.json`，结束后用 netlog-to-har 转换 | 无需侵入代码 | 转换需额外工具，流程繁琐 | ★★ |

推荐组合：**影刀做页面操作 + Playwright 录制 HAR**。在影刀的「Python 指令」节点里跑这段即可：

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    context = browser.new_context(
        record_har_path=r"D:\output\page.har"  # 关闭 context 时自动写盘
    )
    page = context.new_page()
    page.goto("https://目标网址")
    # 在这里做你的页面交互，全部请求都会被记录
    context.close()
    browser.close()
```

- HAR 在 `context.close()` 时才写盘，记得先关闭 context 再取文件
- 只记录指定页面：用完即关 context，不影响其他标签页
- 影刀里如果不想走 playwright，退而求其次用 selenium-wire 也只需 `json.dump(driver.har, f)` 一行

## 架构

```
输入（URL 列表 / 配置文件）
   ↓
Playwright headless（record_har_path 自动落盘）
   ↓
输出（每个 URL 对应一个 .har）
   ↓
触发：Windows 计划任务 / 影刀定时 / 命令行批处理
```

## 可复用脚本骨架

```python
import sys, json, time
from pathlib import Path
from playwright.sync_api import sync_playwright

def export_har(url: str, out_path: str, wait_sec: int = 3) -> str:
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)          # 纯自动关键：无头
        context = browser.new_context(
            record_har_path=out_path,
            record_har_url_filter="*",                       # 可改 "*://api.example.com/*" 只录关键域
        )
        page = context.new_page()
        page.goto(url, wait_until="networkidle", timeout=60000)
        time.sleep(wait_sec)                                 # 兜底等异步请求
        context.close()                                      # HAR 在此刻写盘
        browser.close()
    return out_path

if __name__ == "__main__":
    # 入参：URL 或 URL 列表文件，输出目录
    targets = sys.argv[1:] if len(sys.argv) > 2 else [sys.argv[1]]
    out_dir = Path(sys.argv[-1] if len(sys.argv) > 2 else ".")
    for i, url in enumerate(targets):
        export_har(url, str(out_dir / f"har_{i}_{int(time.time())}.har"))
```

## 三种复用形态

| 形态 | 做法 | 适用 |
|------|------|------|
| 命令行批处理 | `python export_har.py url1 url2 ... 输出目录` | 临时批量导出 |
| 影刀指令封装 | 包成 Python 指令节点，输入=URL+输出目录，输出=HAR 路径列表 | 作为 RPA 流程的可复用子流程 |
| 定时无人值守 | Windows 计划任务/影刀定时任务触发，每天定点跑 | 周期性抓取（如监控接口变更） |

## 复用要点

- **登录态复用**：需要登录的站点，首次手动登录后 `context.storage_state(path="state.json")` 存凭据，之后每次 `new_context(storage_state="state.json")` 免登录
- **录制范围裁剪**：`record_har_url_filter` 指定只录目标 API 域名，HAR 体积可控
- **失败不中断**：单 URL 失败记录日志继续下一个，保证批处理跑完
- **版本锁定**：脚本开头 `pip install playwright && playwright install chromium` 写好依赖说明，换机器一条命令恢复

### [AI · 2026-08-12 13:49:35]

`out_dir` 是 **HAR 文件的保存目录**，即生成的 `.har` 文件写到哪个文件夹。

- 传入一个文件夹的绝对路径，比如 `D:\har_files`，指令运行后会在该目录下生成类似 `har_1723456789.har` 的文件
- 目录不存在会自动创建，不需要你提前建好
- 同一个目录可以反复用：每次运行会按当前时间戳生成新文件名，不会互相覆盖

所以它和你之前问的"输出目录"是一个意思——脚本里的 `out_dir` 对应影刀指令表单里的 `out_dir` 参数，填你想存放抓包结果的文件夹路径即可。
