## 为什么不能换

笔记本 CPU 是 **BGA 封装直接焊死在主板上**的，不是台式机那种 LGA 插座拔插设计。你这台 K3605ZV 出厂时 i7-12650H 就已经焊死在主板上，华硕也没有提供任何官方更换通道。

## 理论上的"邪道"：BGA 返修台换芯

市面上确实有维修店能做"吹焊换 CPU"，同一模具的 K3605 有 i9-13900H 出厂版，理论上主板供电相同、存在换芯可能，但现实非常骨感：

| 风险点 | 说明 |
|---|---|
| 成功率 | 无保底，吹焊过程伤主板/掉点就整机报废 |
| 兼容性 | BIOS/EC 固件、散热策略都要匹配 i9 版，普通店搞不定 |
| 散热 | i9 功耗更高，原 i7 版散热模组未必压得住 |
| 成本 | 拆机+换U+风险溢价，普遍 1500~2500 元 |
| 保修 | 换完直接脱保 |

你这台机器二手残值也就 4000 上下，花一半车钱去赌一个大概率翻车的手术，**性价比是负的**。

## 真正值得做的升级

你这台是 16GB 板载 + **一个空 SO-DIMM 插槽**，升级空间其实在这：

1. **加内存（最优先）**：插一条 32GB DDR4 3200，组成 16+32=48GB，成本 400~500 元。你跑影刀 RPA 多开、vibe coding 挂 IDE+浏览器+虚拟机，内存瓶颈比 CPU 明显得多。
2. **换 2TB SSD**：1T 升 2T 也就几百块，仓库盘自由。
3. **清灰换硅脂**：两三年机器散热衰减明显，清完 CPU 释放会更稳。

一句话：CPU 焊死了动不了，但加内存的收益大概率比你想象中换 CPU 还大。如果你的痛点真是多核性能不够（渲染/编译），直接卖旧换新比折腾这台划算。
