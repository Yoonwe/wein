### [Marvis · 2026-09-04 14:33:24]

老板，yoonup 是一套「技能规范库 + 规则引擎」类型的 MCP 服务，核心作用是把任务按预置技能规范走完整闭环：生成计划 → 执行 → 末端校验，避免交付物漏项或不合规。

## 它能干什么

| 技能 ID | 用途 |
|---|---|
| yoonup-workflow | 通用工作流：提问→读规范→生成计划→执行→校验交付 |
| python-app-standard | Python 流程项目脚手架（目录结构、文件锁、日志、定时任务、飞书通知等） |
| web-js-app-implementation | JS 逆向 + 接口直连抓取网页后台数据，输出影刀可用的二维列表 |

## 提供的 4 个工具

| 工具 | 作用 |
|---|---|
| `list_skills` | 列出可用技能（无参数） |
| `get_skill_spec` | 获取某技能规范全文 + 校验清单 |
| `plan_requirement` | 按需求自动生成执行计划骨架（规则引擎，不依赖 LLM） |
| `check_result` | 对交付目录做末端校验，返回是否通过 + 待核对清单 |

## 标准使用流程

```
list_skills（建立技能上下文）
  → get_skill_spec(技能ID) 读规范
  → plan_requirement(需求) 生成计划
  → 按计划执行，需求拆分时向用户确认顺序
  → check_result(项目目录) 末端校验，未过项修复后重校验
```

## 使用提示

- 需要你的项目目录能被 yoonup 服务端访问（`check_result` 传的是服务端可访问的绝对路径）。
- 该 MCP 是账号级常驻但**不会自动联想触发**，新会话里建议首句点名，例如"按 yoonup 执行 XX 任务"，命中率最高；触发后先调 `list_skills` 建上下文，整会话才顺畅。
- 典型用法举例：想开发一个带日志、定时、飞书通知的 Python 自动化项目，或做一个影刀可用的 JS 抓取任务，都可以直接说"按 yoonup 的 python 规范帮我实现 XX"，我会自动走这套流程并做交付校验。
