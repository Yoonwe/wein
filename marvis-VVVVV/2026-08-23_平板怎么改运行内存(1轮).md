老板，平板改运行内存分两种情况：

## 1. 物理运行内存（RAM）——改不了

平板的内存和手机一样是焊在主板上的，不能像电脑那样加内存条或换内存颗粒，只能买的时候选对大内存版本。

## 2. 虚拟内存扩展（内存融合）——可以在设置里改

这是用部分存储空间（ROM）充当运行内存，各品牌叫法不同，路径也不一样：

| 品牌 | 设置路径 |
|------|---------|
| 华为 / 荣耀 | 设置 → 关于平板 → 运行内存 → 内存扩展（或 设置 → 系统和更新） |
| 小米 / Redmi | 设置 → 更多设置 → 内存扩展 |
| OPPO / 一加 | 设置 → 关于本机 → 运行内存 → 内存扩展 |
| vivo / iQOO | 设置 → 运存与存储空间 → 内存融合 |
| 三星 | 设置 → 电池和设备维护 → 内存 → RAM Plus |
| 联想 / 小新 | 设置 → 高级设置 → 内存扩展 |

**注意事项**：
- 开启后会占用一部分存储空间（通常 2~8GB 可选），存储不够用就别开太大
- 虚拟内存速度远不如物理内存，对提升大型游戏、重度多任务帮助有限，日常使用体验差别不大
- 个别系统版本不支持该功能，属正常现象
