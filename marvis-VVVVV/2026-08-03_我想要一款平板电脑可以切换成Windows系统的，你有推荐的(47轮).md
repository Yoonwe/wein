老板，这类 Windows 二合一平板**大部分都支持**当副屏用，主要分三种方案：

## 方案一：Windows 自带「无线显示器」（最推荐，免费）

- 原理：利用 Miracast 无线投屏协议，把主电脑画面无线投到平板上。
- 操作方法：平板打开「设置 → 系统 → 可选功能 → 添加功能」，安装 **无线显示器**；主电脑按 `Win+K` 搜索并连接即可。
- 支持情况：**Surface Pro、华为 MateBook E、联想异能者、酷比魔方** 等几乎所有运行 Windows 11 的平板都支持，前提是主电脑和平板在同一 Wi-Fi 下。
- 局限：有一定延迟（约 50–100ms），适合文档、网页、PPT 办公场景；**不适合**游戏、视频剪辑等对延迟敏感的操作。

## 方案二：第三方软件扩展副屏（功能最强）

| 软件 | 特点 | 适用 |
|------|------|------|
| **Spacedesk** | 免费，跨平台，可把平板变成真正的扩展屏（非镜像），支持触控回传 | Windows 平板、安卓平板均适用 |
| **Duet Display** | 有线/无线均可，延迟低，支持触控笔压感 | 追求低延迟 |
| **Parsec** | 串流方案，延迟极低，支持远程 | 跨网络、异地扩展 |

- 平板端安装对应 App，主电脑安装驱动端，即可把平板识别为**第二显示器**（可独立拖动窗口，比镜像实用）。
- Spacedesk 免费且支持触控，是性价比最高的方案。

## 方案三：硬件视频输入（仅个别机型支持）

少数型号带 **HDMI-IN** 接口，可直接用线缆把电脑画面输入平板显示，延迟最低且不占网络。但**上述推荐的主流机型（Surface Pro、MateBook E、联想异能者、宏碁 A525 等）都不带 HDMI-IN**，此方案基本可以排除。

## 结论

- 你选**任意一款 Windows 二合一平板**，都能当副屏：日常办公用「无线显示器」零成本搞定；需要拖拽窗口、触控操作就用 Spacedesk。
- 如果副屏需求是刚需，**建议优先选 Surface Pro 或 MateBook E 这类主流机型**，驱动和投屏兼容性更稳；千元入门款投屏稳定性会差一些。

## 1. 当电脑副屏：有，而且做得不错

OPPO 和 vivo 的平板都有连接 Windows 电脑当副屏的功能，走的是各自生态的互联软件：

| 品牌 | 功能名称 | 连接方式 | 副屏能力 |
|------|---------|---------|---------|
| OPPO | OPPO 多屏互联（PC 客户端） | 平板装 App + 电脑装客户端，局域网连接 | 可作为无线扩展屏，支持触控、拖拽窗口 |
| vivo | vivo 办公套件 | 平板装 App + 电脑装客户端 | 支持扩展屏模式、文件互传、剪贴板共享 |

两者体验上都是「无线副屏」方案，延迟表现和前面说的 Spacedesk 差不多，日常办公够用。

## 2. 切换成 Windows 系统：没有

这是本质区别，需要说明白：

- **OPPO/vivo 平板运行的是安卓系统（ColorOS / OriginOS）**，硬件是 ARM 架构，出厂就是安卓，**无法原生切换到 Windows 系统**。
- 想在这类平板上用 Windows，只有三条路，但体验都打折：
  - **云电脑/远程桌面**（如 ToDesk、向日葵、华为云电脑）：画面串流，办公能用，但依赖网络，延迟明显；
  - **Winlator 等模拟器**：在安卓上模拟 x86 环境，能跑些老软件，性能差、兼容性一般；
  - **双系统刷机**：极少数型号有民间适配，风险高、驱动不全，不推荐。

## 结论

- 你的核心诉求如果是「**安卓平板的便利 + 偶尔切 Windows 用桌面软件**」→ OPPO/vivo 平板做不到系统级切换，只能远程串流；
- 如果诉求是「**原生 Windows + 平板形态 + 当副屏**」→ 还是要选上一轮推荐的 Windows 二合一平板（Surface Pro、MateBook E 等），这类设备副屏和 Windows 系统两样都满足。
