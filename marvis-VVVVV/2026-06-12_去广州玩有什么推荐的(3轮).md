广州作为千年商都和美食之都，值得玩的地方很多。以下按类型梳理：

## 经典景点

| 类型 | 推荐 | 亮点 |
|------|------|------|
| 地标 | 广州塔 | 夜景最佳，可登塔俯瞰珠江新城 |
| 历史 | 陈家祠 | 岭南建筑巅峰，砖雕木雕精美 |
| 欧陆风情 | 沙面岛 | 百年租界建筑群，适合拍照 |
| 近代史 | 中山纪念堂 | 八角形宫殿式建筑，蓝瓦红柱 |
| 老城烟火 | 永庆坊 / 西关大屋 | 骑楼老街，感受老广生活气息 |
| 自然 | 白云山 | 市内登高首选，山顶俯瞰全城 |

## 必吃美食

| 类别 | 推荐 |
|------|------|
| 早茶 | 点都德、陶陶居、广州酒家（虾饺、凤爪、红米肠必点） |
| 烧腊 | 叉烧、烧鹅（文明路、长寿路一带老店） |
| 糖水 | 南信双皮奶、百花甜品、顺记冰室 |
| 煲仔饭 | 北京路附近的街边老铺 |
| 生猛海鲜 | 黄沙水产市场，现捞现做 |

## 一日游路线参考

- **上午**：陈家祠 → 永庆坊 → 上下九步行街
- **中午**：上下九或宝华路吃地道小吃
- **下午**：沙面岛 → 石室圣心大教堂 → 珠江新城花城广场
- **晚上**：广州塔 / 珠江夜游

## 实用贴士

- 地铁覆盖核心区域，微信/支付宝扫码乘车即可
- 6 月天气炎热多雨，带伞、穿轻便透气的衣物
- 老城区（荔湾、越秀）美食更地道，价格也比天河亲民

如果有具体的偏好方向（比如更偏美食、拍照、亲子还是深度人文），可以进一步细化推荐。

广州是公认的美食之都，"食在广州"名不虚传。以下按类别和区域整理核心推荐：

## 早茶（来广州必体验）

| 茶楼 | 特色 | 人均 |
|------|------|------|
| **广州酒家** | 老字号，文昌路总店最正宗 | 80-120 |
| **陶陶居** | 百年老店，第十甫路总店环境好 | 80-120 |
| **泮溪酒家** | 荔湾湖畔园林式茶楼，环境一绝 | 70-100 |
| **点都德** | 连锁但品质稳，红米肠一绝 | 60-90 |
| **白天鹅宾馆·玉堂春暖** | 高端早茶天花板，沙面岛 | 150-250 |

**必点**：虾饺、干蒸烧卖、凤爪、红米肠、流沙包、蛋挞

## 各区美食地图

### 荔湾（西关老城，地道小吃集中地）

| 店名 | 招牌 | 地址参考 |
|------|------|------|
| **南信牛奶甜品专家** | 双皮奶、姜撞奶 | 第十甫路 |
| **陈添记** | 爽鱼皮、艇仔粥 | 宝华路 |
| **顺记冰室** | 芒果雪糕、椰子雪糕 | 宝华路 |
| **银记肠粉** | 鲜虾肠、牛肉肠 | 上下九 |
| **吴财记面家** | 云吞面、炸云吞 | 大同路 |

### 越秀（老城区，烧腊煲仔饭主场）

| 店名 | 招牌 | 地址参考 |
|------|------|------|
| **超记煲仔饭** | 腊味煲仔饭、窝蛋牛肉 | 珠光路 |
| **民记煲仔饭** | 40年老店，黄鳝煲仔饭 | 惠福东路 |
| **九爷鸡** | 豉油鸡、叉烧 | 文明路 |
| **达扬原味炖品** | 椰子炖竹丝鸡 | 文明路 |
| **百花甜品** | 凤凰奶糊、红豆沙 | 文明路 |

### 海珠（宵夜与排档天堂）

| 区域 | 推荐 |
|------|------|
| **宝业路** | 宵夜一条街，砂锅粥、烧烤、潮汕菜 |
| **江南西** | 日料、甜品、咖啡店密集区 |
| **太古仓** | 江边酒吧+音乐餐吧，适合晚上去 |

### 天河（新派餐饮与融合菜）

| 类型 | 推荐 |
|------|------|
| 高端粤菜 | 炳胜品味、惠食佳（啫啫煲鼻祖） |
| 潮汕菜 | 海门鱼仔店 |
| 东南亚 | 体育西横街整条街 |

## 按菜式专项推荐

### 烧腊
- **文明路/长寿路一带老铺**：烧鹅、叉烧、烧肉，街坊店最稳
- **妙栈烧腊**（东山口）：老广心中的烧腊白月光

### 糖水/甜品
- **南信**：双皮奶（必吃）
- **百花甜品**：400多款糖水，眼花缭乱
- **芬芳甜品**（同福路）：糖不甩、杨枝甘露
- **玫瑰甜品**（文明路）：杏仁豆腐

### 牛杂
- **阿婆牛杂**：芳村陆居路（需要碰运气）
- **文记牛杂**：荔枝湾涌附近

### 海鲜
- **黄沙水产市场**：自己挑海鲜，旁边酒楼加工，新鲜价优
- **南沙十九涌**：远一点但海鲜更新鲜便宜

### [Marvis · 2026-06-12 13:19:50]

永庆坊在荔湾恩宁路，属于西关腹地，周边是广州小吃密度最高的区域之一。以下按从永庆坊步行可达的距离整理：

## 永庆坊内及紧邻

| 店名 | 推荐 | 说明 |
|------|------|------|
| **恩宁雪糕行** | 花椒味 / 姜撞奶味雪糕 | 网红打卡店，味道确实有惊喜 |
| **钟巷鸡煲** | 炭炉鸡煲 | 恩宁路老字号，清补凉汤底，鸡肉鲜嫩 |
| **哥林多三文治** | 招牌三文治 | 街坊价，简单但好吃，适合边走边吃 |

## 步行 3-5 分钟：宝华路 / 第十甫路

永庆坊往南走就是宝华路，老字号密度极高，可以一路吃过去：

| 店名 | 必点 | 亮点 |
|------|------|------|
| **陈添记** | 爽鱼皮、艇仔粥 | 只卖三样东西，鱼皮爽脆无腥味 |
| **顺记冰室** | 椰子雪糕、芒果雪糕 | 百年冰室，手工雪糕是广州一绝 |
| **南信牛奶甜品专家** | 双皮奶、姜撞奶 | 广州双皮奶代名词 |
| **宝华面店** | 云吞面 | 汤底大地鱼熬制，鲜香浓郁 |

## 步行 5-8 分钟：上下九 / 第十甫路

| 店名 | 必点 | 亮点 |
|------|------|------|
| **银记肠粉（上九路店）** | 鲜虾肠、韭黄牛肉肠 | 广州肠粉名片，皮薄滑嫩 |
| **莲香楼** | 鸡仔饼、莲蓉月饼 | 手信首选，买回去当伴手礼 |
| **陶陶居** | 虾饺、烧卖、蛋挞 | 早茶去第十甫路总店，装潢复古华丽 |

## 步行 8-10 分钟：荔枝湾 / 龙津西路

| 店名 | 必点 | 亮点 |
|------|------|------|
| **泮溪酒家** | 马蹄糕、荔浦芋角 | 紧邻荔枝湾湖，园林里饮茶 |
| **凌记濑粉** | 招牌濑粉 | 西关濑粉代表，米浆浓滑 |
| **伍湛记粥品** | 及第粥、艇仔粥 | 老字号粥底，龙津路老店 |
| **成裕雪糕店** | 薄饼夹雪糕 | 怀旧老式雪糕，荔枝湾边 |

## 永庆坊逛吃路线建议

1. **永庆坊**逛一圈 → 出来**恩宁路**吃雪糕
2. 沿**多宝路**走到**宝华路**：陈添记 → 顺记冰室 → 南信双皮奶（一路吃过去）
3. 往西到**荔枝湾涌**散步消食，顺便泮溪酒家或凌记濑粉
4. 晚上回头**上下九**看骑楼夜景，银记肠粉收尾

这一圈下来，早茶点心、肠粉、糖水、鱼皮、雪糕、濑粉全齐，步行全程不超过 2 公里。
