## GitHub 中文汉化方案详细说明

以下插件为**浏览器扩展/油猴脚本**，需通过浏览器扩展商店或脚本平台获取，不属于应用宝分发范围：

### 1. GitHub 汉化插件（最推荐）
- **类型**：浏览器扩展（Chrome/Edge/Firefox）
- **开源项目**：maboloshi/github-chinese
- **获取渠道**：
  - Chrome/Edge 应用商店搜索 "GitHub 汉化插件"
  - GitHub Releases 页面下载 .crx 离线安装
- **核心功能**：
  - 全界面深度汉化（菜单、按钮、标题、描述）
  - 支持简体中文、繁体中文切换
  - 智能识别动态加载内容（弹窗、下拉菜单）
  - 开源免费，无广告
- **安装方式**：浏览器扩展商店一键安装，或下载 .crx 手动加载

### 2. GitHub 增强 - 极致化
- **类型**：浏览器扩展
- **开源项目**：ZS-Plus/ZS-Plus
- **获取渠道**：
  - Chrome/Edge 应用商店搜索 "GitHub 增强" 或 "ZS Plus"
  - GitHub Releases 下载 .crx/.zip 安装
- **核心功能**：
  - 汉化 + 功能增强二合一
  - 显示文件大小、行提交信息、一键复制文件内容
  - 图片预览、代码高亮优化
  - 针对国内网络优化加载速度
- **安装方式**：扩展商店安装后，需在设置中启用"中文翻译"选项

### 3. GitHub 汉化油猴脚本（备用方案）
- **类型**：油猴脚本（Tampermonkey/GreasyFork）
- **获取渠道**：GreasyFork 脚本平台搜索 "GitHub 汉化"
- **核心功能**：
  - 轻量级自动翻译
  - 访问 GitHub 时自动替换为中文
  - 即时更新，无需手动操作
- **安装方式**：
  1. 先安装 Tampermonkey 浏览器扩展
  2. 访问 GreasyFork 搜索并安装脚本
  3. 刷新 GitHub 页面即可生效

---

## 本地环境状态
- **引擎版本**：5.10.70.10（支持应用操作）
- **可安装应用**：仅检测到 Tampermonkey 手机版可通过本环境安装
- **浏览器扩展类插件**：需手动通过浏览器扩展商店或 GitHub 开源页面获取安装

**建议**：优先使用 **GitHub 汶化插件（方案1）**，翻译覆盖最全且体验最佳；如需更多增强功能可选择 **GitHub 增强 - 极致化（方案2）**；受限环境下可使用 **油猴脚本（方案3）** 作为备选。
