选 **Fine-grained personal access token**（细粒度），更安全，理由：

| 对比 | Fine-grained | Classic |
|------|-------------|---------|
| 权限范围 | 可精确到单个仓库 | 全局所有仓库 |
| 权限项 | 按需勾选（如只给 Contents: Read and write） | 粗粒度（repo 全选） |
| 泄露风险 | 只影响授权仓库 | 影响账号下全部仓库 |
| 有效期 | 可设 7~90 天 | 最长不过期 |

操作步骤：
1. 点 **Generate new token** → **Fine-grained, repo-scoped**
2. Repository access 选 **Only select repositories**，勾选你要让我操作的那个仓库
3. Permissions → Repository permissions → **Contents** 设为 **Read and write**（改代码、推文件必需）；若还要操作 Issues/PR 再对应勾选
4. 生成后把 token 发我（只发 token 本身即可，仓库地址我自己查），我通过环境变量或配置文件方式使用，不会写进任何文档

注意：token 等同于密码，发我之后建议设个 30~90 天的有效期，到期重新授权。
