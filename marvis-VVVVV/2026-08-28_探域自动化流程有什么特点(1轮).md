## 核心模式：一个指令，自动执行，交付结果

运营人员只需发一句"@运助Agent 请开始处理今天的工作"，系统自动读取任务来源，按既定 SOP 依次完成商品上架、素材填充、活动报名等动作。交付的不是一句"已处理"，而是明确结果——例如"已成功上架 10 个商品链接"。

## 四大特点拆解

| 特点 | 说明 |
|------|------|
| **动作原子化** | 把高频经营动作拆成可执行的 Tool，首批覆盖上架、素材、活动、投放四类原子任务，背后是覆盖商品、素材、链接、活动、流量五大分类的完整任务库 |
| **SOP 流程化** | 通过 Skill 编排工作流，把运营标准作业流程沉淀为企业可复用的流程资产，解决"方法论锁在个人手里"的问题 |
| **双 Agent 协同闭环** | 运营 Agent 负责采集数据、诊断分析、给出优化建议 → 人工确认 → 运助 Agent 调用工具执行并交付结果。首次把"经营判断 + 人工确认 + 执行交付"放进同一个闭环，保留了人的决策权 |
| **全链路覆盖** | 从客服场景延伸到运营管理，覆盖"服务—运营—管理"全链路；客服端还有 AI 智席的人机协同模式（AI 负责高频咨询，人工负责复杂服务） |

## 技术底座

- 自研电商垂直大模型 ShopGLM，接入 DeepSeek、豆包优化
- GraphRAG 知识库（商品详情、金牌客服聊天记录、店铺知识多来源学习）
- 开箱即用、越用越智能，0 配置可自主学习和优化
